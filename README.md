# أتمتة قناة اللقطة (Al Laqta) — نظام كامل مجاني

نظام أتمتة كامل بينشر فيديوهات على يوتيوب **8 مرات يوميًا** من غير أي تدخل بشري بعد الإعداد الأولي، وكل مكوناته مجانية:

**المسار الأساسي المستقر هو `Publish Video (Automated)`** للفيديوهات المعلوماتية والقصص. أما الأغاني فلها Workflow منفصل بدون API موسيقى مدفوع: توليد الصوت يدويًا عبر واجهة ACE-Step المجانية، ثم بناء الفيديو العمودي ورفعه آليًا من GitHub بعد إضافة ملف الأغنية إلى `music_input/song.mp3`.

| المرحلة | الأداة | التكلفة |
|---|---|---|
| كتابة السكريبت (مقسّم لمشاهد) | Groq API | مجاني/رخيص جداً (عندك المفتاح) |
| التعليق الصوتي | edge-tts (أصوات Microsoft Edge العصبية) | مجاني 100% |
| مقاطع الفيديو | Pexels (فيديوهات ستوك حقيقية بدون حقوق) | مجاني 100% |
| تركيب الفيديو + الكتابة على الشاشة | FFmpeg | مجاني 100% |
| الرفع على يوتيوب | YouTube Data API | مجاني 100% |
| الجدولة والتشغيل | GitHub Actions | مجاني (بشرط الريبو Public) |

---

## ⚠️ 3 حقائق مهمة قبل ما تبدأ

1. **edge-tts خدمة غير رسمية** من مايكروسوفت (مش API معلن رسميًا للمطورين)، شغالة ومجانية دلوقتي وبيستخدمها آلاف المطورين، لكن نظريًا ممكن تتغير أو تتوقف من غير سابق إنذار. لو حصل كده، هنحتاج نبدّلها ببديل (زي Google Cloud TTS اللي فيه رصيد مجاني شهري محدود).
2. **الريبو لازم يكون Public** عشان تستفيد من دقائق GitHub Actions المجانية بلا حدود. الريبوهات الـ Private ليها حد 2000 دقيقة/شهر مجانًا، وممكن تخلص بسرعة مع فيديو كل 6 ساعات. متقلقش على أمان مفاتيحك — الـ Secrets بتفضل مخفية حتى لو الريبو Public.
3. **محتوى مولّد بالكامل بالذكاء الاصطناعي وبدون مراجعة بشرية بيحمل مخاطرة سياسات يوتيوب**: يوتيوب بدأ يشدد على المحتوى "المكرر أو المصنّع بكميات كبيرة بدون قيمة مضافة" فيما يخص الأهلية للربح (Monetization). يُنصح تراجع فيديو من كل دفعة بشكل دوري للتأكد من الجودة، ولو حابب تفعّل شارة "محتوى مولّد بالذكاء الاصطناعي" في إعدادات يوتيوب (مطلوبة بحسب سياسة يوتيوب للمحتوى الواقعي المصطنع).

## 1) هيكل المشروع

## 2) الإعداد لأول مرة

### أ) اعمل الريبو
اعمل ريبو جديد على GitHub، واختاره **Public** (السبب في الملاحظة رقم 2 فوق). ارفع كل ملفات المشروع.

### ب) مفاتيح YouTube (زي ما اتفقنا قبل كده)
1. [Google Cloud Console](https://console.cloud.google.com/) → مشروع جديد → فعّل **YouTube Data API v3**.
2. OAuth consent screen → External → ضيف حسابك كـ Test User.
3. Credentials → Create OAuth client ID → نوعه **Desktop app** → نزّل `client_secrets.json`.
4. على جهازك: `pip install -r requirements.txt` ثم `python get_refresh_token.py` — هتاخد `client_id` و`client_secret` و`refresh_token`.

### ج) مفتاح Pexels (مجاني)
1. سجّل في [pexels.com/api](https://www.pexels.com/api/) بإيميلك (تسجيل فوري، بدون بطاقة ائتمان).
2. هتاخد API key فورًا من الداشبورد.
3. الحد المجاني: 200 طلب/ساعة و20,000 طلب/شهر — كافي جدًا لـ 8 فيديوهات يوميًا (كل فيديو بيستخدم ~10-12 طلب بحث).

### د) ضيف الـ Secrets في GitHub
Settings → Secrets and variables → Actions → New repository secret:

| اسم الـ Secret | القيمة |
|---|---|
| `GROQ_API_KEY` | مفتاح Groq بتاعك |
| `PEXELS_API_KEY` | من خطوة (ج) |
| `YT_CLIENT_ID` | من client_secrets.json |
| `YT_CLIENT_SECRET` | من client_secrets.json |
| `YT_REFRESH_TOKEN` | من خطوة (ب-4) |

### هـ) جهّز قائمة المواضيع
افتح `topics.txt` وضيف مواضيع (موضوع في كل سطر). النظام بياخد أول سطر في كل مرة يشتغل، فلازم تتابع وتضيف مواضيع جديدة بشكل دوري (هيظهرلك تحذير في الـ Actions log لما يبقى باقي 4 مواضيع بس).

## 3) بعد كده، مفيش حاجة تعملها

بمجرد ما الإعداد يخلص، سيعمل `Publish Video (Automated)` لوحده **8 مرات يوميًا** (الساعات مضبوطة في `publish_video.yml`). كل مرة:

1. ياخد أول فكرة من `topics.txt`
2. Groq يكتب سكريبت حلقة معلوماتية أو قصة حسب الموضوع
3. edge-tts يحوّل الكلمات إلى صوت عربي
4. ينشئ موسيقى خلفية إيقاعية مجانية بـ FFmpeg
5. Pexels يوفّر مقاطع فيديو لكل مشهد
6. FFmpeg يركب الصوت والموسيقى والصورة والكتابة على الشاشة
7. يرفع الفيديو على يوتيوب مباشرة كـ Public

تقدر تتابع كل تشغيلة من تبويب **Actions**، وهتلاقي الفيديو النهائي والسكريبت وبيانات النشر وملف الترجمة `captions_ar.srt` محفوظين كـ Artifact لمدة 7 أيام. الترجمة العربية بتظهر داخل الفيديو على مقاطع قصيرة متزامنة تقريبًا مع الكلام، وملف SRT متاح كنسخة منفصلة للمراجعة أو الرفع اليدوي.

### الديباجة والهاشتاجات التلقائية

قبل رفع كل فيديو، النظام بيجهز تلقائيًا:
- عنوان مناسب للموضوع.
- ديباجة عربية فيها افتتاحية من أول التعليق الصوتي، شرح مختصر ودعوة للتفاعل.
- هاشتاجات داخل الوصف نفسه، بالإضافة إلى كلمات البحث (Tags) في بيانات يوتيوب.
- تصنيف يوتيوب مناسب: القصص «ترفيه»، والعلوم/التكنولوجيا/الفضاء «علوم وتكنولوجيا»، وباقي الفيديوهات المعلوماتية «تعليم».

مسار الأغاني بيضيف ديباجة موسيقية وهاشتاجات الأغاني تلقائيًا. كل ده بيتجهز في `content.json` قبل الرفع، ومش محتاج كتابة يدوية لكل فيديو.

---

## 4) تشغيل يدوي لموضوع معين (اختياري)

من تبويب **Actions** → **Publish Video (Automated)** → **Run workflow**، اكتب موضوعًا في حقل `manual_topic` لو عايز فيديو محدد خارج الطابور. اترك الحقل فارغًا لاستخدام قائمة `topics.txt` المعتادة، ولن يُستهلك موضوع من القائمة عند استخدام موضوع يدوي.

---

## 5) لو حبيت تعدّل لاحقًا

- **تغيير صوت الراوي**: غيّر `TTS_VOICE` في `scripts/generate_voice.py` (أصوات عربية تانية متاحة: `ar-EG-SalmaNeural`, `ar-SA-HamedNeural`, `ar-SA-ZariyahNeural`).
- **تغيير عدد مرات النشر**: عدّل سطر `cron` في `publish_video.yml`.
- **تغيير مدة الفيديو**: عدّل عدد الكلمات المطلوب في `scripts/generate_script.py` (تم ضبطه حالياً لحوالي 3 دقائق للفيديو المعلوماتي).


## 6) مسار الأغاني المجاني (بدون API مدفوع)

لتجنب رسوم خدمات توليد الموسيقى، نولّد الأغنية يدويًا من واجهة ACE-Step المجانية، ثم يتولى GitHub بناء فيديو عمودي ورفعه. التوليد المجاني من الواجهة ليس خدمة API مضمونة بلا حدود، لذلك لا ندّعي أن توليد الأغنية نفسه مجدول بالكامل.

### إنشاء الأغنية مجانًا

1. افتح [واجهة ACE-Step 1.5 الرسمية على Hugging Face](https://huggingface.co/spaces/ACE-Step/Ace-Step-v1.5).
2. اكتب وصفًا موسيقيًا، والصق كلمات الأغنية المصرية الأصلية، ثم اضغط Generate وانتظر النتيجة. قد يكون هناك انتظار أو حدود استخدام بحسب توفر المساحة المجانية.
3. نزّل النتيجة الصوتية بصيغة MP3 باسم \`song.mp3\`.

### بناء الفيديو ورفعه تلقائيًا

1. افتح مجلد \`music_input\` في المستودع. ارفع ملف MP3 من خلال Add file → Upload files، واجعل مساره النهائي \`music_input/song.mp3\` ثم احفظ التغيير.
2. افتح [Workflow: Free Music Video (Manual Song)](https://github.com/matador200499-ctrl/al-laqta-automation/actions/workflows/daily_music_video.yml).
3. اضغط Run workflow وأدخل عنوان الأغنية وموضوعها.
4. سيجمع GitHub الفيديو العمودي بمقاطع Pexels، ويحفظ معاينة كـ artifact لمدة 7 أيام، ثم يرفع الفيديو علنًا إلى يوتيوب.

**تنبيه خصوصية مهم:** المستودع Public، لذلك أي ملف ترفعه إلى `music_input/song.mp3` سيكون متاحًا للعامة. ارفع فقط أغنية تملك حق مشاركتها علنًا. لا ترفع أي مفاتيح API أو ملفات OAuth أو بيانات حسابات.

### المتطلبات والتكلفة

- لا يحتاج هذا المسار إلى \`FAL_KEY\` أو \`ACE_STEP_API_URL\`، ولا يشغّل أي خدمة GPU مدفوعة.
- يحتاج إلى الأسرار المجانية/الموجودة بالفعل: \`PEXELS_API_KEY\` وبيانات رفع يوتيوب \`YT_CLIENT_ID\` و\`YT_CLIENT_SECRET\` و\`YT_REFRESH_TOKEN\`.
- لا تضغط Run workflow قبل رفع ملف الأغنية الصحيح؛ خطوة التحقق ستوقف التنفيذ إن كان الملف مفقودًا.
- مسار الأغاني مستقل عن جدول الفيديوهات المعلوماتية والقصصية. لا يوجد نشر مجدول للأغاني في هذا الوضع المجاني؛ توليد الصوت يتم يدويًا، وبناء الفيديو والرفع يُنفّذان من خلال Workflow.
